# Bugcon CTF 2026 — PaySec Village

**Categoría:** Mobile / Hardware / API Security  
**Organización:** PaySec Latam  
**Evento:** BugCon 2026

---

## Descripción

Bienvenido al reto de seguridad de PaySec Village. Tienes acceso a un ecosistema mPOS completo:

- **APK Android** — aplicación de punto de venta móvil
- **Backend API** — servidor de pagos con múltiples endpoints
- **Hardware BLE** — lector físico ESP32 simulando un miniPOS real

Tu objetivo es encontrar vulnerabilidades reales en cada capa del sistema y capturar las flags.

---

## Instrucciones

1. Instala el APK
2. Regístrate una cuenta
3. Explora la aplicación, el backend y el hardware BLE
4. Cada flag tiene el formato `FLAG{...}`
5. Documenta cada hallazgo y envía tu reporte

No hay scoreboard público. Los reportes se envían directamente al organizador.

---

## Envío de flags

Envía un mensaje a Telegram **[@stuxnet](https://t.me/stuxnet)** por cada flag encontrada con el siguiente formato:

```
[BUGCON2026 - PAYSEC]

Flag: FLAG{...}

Descripción del problema:
<qué vulnerabilidad encontraste>

Cómo reproducirlo:
<pasos exactos para llegar a la flag>
```

Un reporte bien documentado vale más que solo la flag.
